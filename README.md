# Jamaica Vacation

Installable web app for planning a Jamaica trip from the Dallas area.

Live site: https://phillipalvaranga-arch.github.io/jamaica-vacation/

This app is informational only. It never books a flight, room or rental car and never collects card or passport numbers. Flight, hotel and car-rental prices are not invented — buttons open live searches.

Facts were researched on November 22, 2026. Hotel opening status after Hurricane Melissa can change; always check Visit Jamaica and the official resort site.
